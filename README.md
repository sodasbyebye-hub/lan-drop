# 局域网快传

一台 Windows 电脑运行服务，同一局域网中的手机和电脑即可通过浏览器互传文件。无需账号，文件不会上传到互联网。

## 启动

双击 `start-lan.cmd`。服务会以后台常驻方式运行，关闭启动窗口不会中断聊天或文件传输。需要停止服务时双击 `stop-lan.cmd`。启动窗口会显示局域网地址，例如：

```text
http://192.168.1.20:3000
```

在其他设备上打开该地址，或在网页右上角打开二维码后扫码访问。首次运行若 Windows 防火墙询问是否允许访问，请选择允许专用网络访问。

## 功能

- 顶部“媒体库”支持独立上传，也会自动收录现有及新发送的聊天图片、视频。图片区与视频区分别以响应式网格展示；悬浮卡片查看配文，点击可查看完整图片或播放视频，手机支持点击查看。
- 上传时可为每个素材单独配文，之后可用卡片上的编辑按钮修改（最多 1000 字）；可查看该素材的设备可共同编辑配文。独立上传与公共聊天素材在局域网共享，私聊素材仅原会话双方可见。
- 媒体库原文件长期保留，不随聊天记录过期清理。图片和视频分别存储在 `data/media/images`、`data/media/videos`，索引和配文保存在 `data/media/index.json`；聊天素材自动去重，同盘支持时通过硬链接保留原文件，避免重复占用空间。
- 同一条消息中的多张图片以卡片堆叠显示，鼠标悬浮或点击可展开，手机支持点击展开。展开后可逐张下载原图，也可点击“下载全部”依次保存全部原图（不压缩、不打包）；若浏览器提示，请允许该网站下载多个文件。混合发送的视频和其他文件仍单独显示。
- 每次进入、刷新页面或切换聊天时自动定位到最新消息；图片和视频加载后继续保持在底部，手动向上翻阅时可正常查看历史消息。
- 加入时自动按设备信息命名（如 Windows 电脑、iPhone、iPad；安卓在浏览器提供型号时显示型号），不再生成随机昵称。旧随机名称在刷新后自动替换，手动名称保留。点击头像可改名，清空后保存可恢复自动命名。
- 浏览器无法直接读取系统中自定义的设备名称，部分浏览器也会隐藏型号，因此自动名称可能只显示设备类型；同类型设备可手动改名区分。
- 查看同一网页中的在线设备，向指定设备发送多个文件
- 文件以聊天消息形式直接发送，实时显示上传进度；接收方在会话中点击下载
- 公共文件柜中的文件保留 24 小时，上传者可提前删除
- 私人传输保留 1 小时，完成下载后自动清理
- 不设固定单文件大小上限，文件采用流式传输和磁盘存储（实际受主机磁盘空间与浏览器限制）

## 开发

```text
npm.cmd install
npm.cmd run dev
```

默认监听 `0.0.0.0:3000`。可以通过 `PORT` 环境变量调整端口。运行测试使用 `npm.cmd test`。
